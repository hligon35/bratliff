# Workspace clean-up review (analysis only — nothing has been deleted)

Method: `git ls-files`, `git status --ignored`, and a text search of every tracked HTML/JS/CSS/TS/JSON/MD/YAML file for references to each candidate. "Unreferenced" means no tracked file mentions the file name; it does not prove the file is unused (a human may link to it from outside the repo, e.g. an email or social post). Confidence is stated per item.

## 1. Environment / variable files

How configuration actually flows:

| Where | Used by | What it holds |
|---|---|---|
| `cloudflare/wrangler.jsonc` `vars` (per env) | the deployed Worker | non-secret settings (URLs, `SQUARE_ENVIRONMENT`, `MAIL_FROM_EMAIL`, …) |
| Cloudflare Worker secrets (`wrangler secret put/bulk`) | the deployed Worker | the 9 secrets (Resend, Namecheap, Square, Turnstile, session, unsubscribe, Google) |
| `.env`, `.env.local`, `.env.example` | `scripts/write-site-config.js` (build-time: site URL, Turnstile **site** key, Google client id, Square payment links) | local only |
| `.env.local` | `scripts/bootstrap-sandbox.mjs` (must say `SQUARE_ENVIRONMENT=sandbox`), `scripts/generate-review-data.mjs`, `wrangler dev` | sandbox values |
| `.secrets.sandbox` | only `generate-review-data.mjs` (loaded after `.env.local`, overriding it) | |

The deployed Worker never reads any local file.

| File | Tracked? | Finding | Recommendation |
|---|---|---|---|
| `.env.example` | yes | The template; the only env file that should be in git. | **Keep** |
| `.env.local` | ignored | Sandbox values (`SQUARE_ENVIRONMENT=sandbox`) plus the Namecheap password. Needed by the sandbox bootstrap and review-data scripts. Its `SITE_URL` is the old `jrpp.alphazonelabs.com`. | **Keep** — this is the one working local file. Update `SITE_URL` to the sandbox URL. |
| `.env.local2` | ignored | Production values (`SQUARE_ENVIRONMENT=production`). Referenced by nothing except `.gitignore`. It is currently your only on-disk copy of the production secrets. | **Do not delete until the values are in a password manager.** Then rename to something that says what it is (e.g. `.env.production.local`) or remove. |
| `.secrets.sandbox` | ignored | Same keys and (except the Namecheap password) the same values as `.env.local`. | **Redundant — delete** (then drop the `.secrets.sandbox` line from `generate-review-data.mjs` and `README.md`). |
| `cloudflare/.env.example` | ignored (by `.env*`) | A comment-only checklist, "not read by any script". Duplicates `.env.example` and the `secrets.required` block in `wrangler.jsonc`. | **Redundant — delete** |
| `worker-configuration.d.ts` | yes | 608 KB generated by `wrangler types`, pinned to an old workerd (`1.20260831`). `cloudflare/tsconfig.json` has `types: []` and includes only `cloudflare/src`, so it is not used by the type check. Nothing references it. | **Delete** (regenerate with `wrangler types` if ever wanted) |

Minimum set to keep: `.env.example` (committed), `.env.local` (sandbox, local), and the Cloudflare-side secrets. Keep production values in a password manager, not as a working file.

## 4. Weight / performance clutter (not dead, but heavy)

- `assets/documents/JPP_Media_Press_Kit_09222026.pdf` is **16.5 MB** and `JPP_Certificate_of_Appreciation_09222026.pdf` is 3.6 MB. Consider R2 or compression.
- Many unoptimized PNGs of 2–2.8 MB each in `assets/books`, `assets/photos`, `assets/icons` (`pieMystery.png`, `battles2.png`, `charlesRatliff.png`, `barbaraRatliff3.png`, `femaleFeature.png`, `LTGold.png`, …). WebP/resized versions would cut payload substantially.
- `assets/admin.js` (116 KB) and `admin.css` (38 KB) are still one monolith loaded on every non-workspace admin page (noted earlier; not split).

## 5. Dependencies

`jose` is used by the Worker. `typescript` and `wrangler` are needed. `dotenv` is used by `write-site-config.js` and the two sandbox scripts. `http-server` and `open-cli` are used only by the optional `dev`/`open` scripts (section 2). Open dependabot branches for `dotenv 17`, `open-cli 9` and `typescript 7` are unmerged; `typescript 7` is a major jump to test before merging.

## 6. Local, ignored folders (no repo impact)

`.venv/` (Python env for the cover script, with `.pyc` files), `cloudflare/.wrangler/`, `cloudflare-proxy/.wrangler/`, `cloudflare/public/` (regenerated staging), `node_modules/`. Safe to delete locally; all are regenerated or unneeded.

## 7. Suggested clean-up order (lowest risk first)

1. Delete `.secrets.sandbox`, `cloudflare/.env.example`, `worker-configuration.d.ts`, `assets/finalUpdates.txt`; remove `.secrets.sandbox` mentions in `README.md` and `generate-review-data.mjs`.
2. Back up `.env.local2` into a password manager.
3. Delete `CNAME` and `.nojekyll` (and the `.nojekyll` entry in `stage-cloudflare-assets.js`) after confirming GitHub Pages is disabled.
4. Decide on `dev`/`start`/`open`, `cloudflare-proxy/` + `proxy:deploy`, and `generate-resource-covers.py`.
5. Verify, then delete unreferenced images and PDFs.
6. Decide whether to keep the monthly maintenance system; if not, remove its scripts, tests, workflow and `monthlyReport.md`.
7. Optimize the large PDFs and PNGs.

After any removal run `npm run worker:check` and `npm run test:maintenance` (the static-guard tests reference the workflow and `monthlyReport.md`, so they would need updating if those go).
